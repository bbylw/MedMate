# 循证药安 (MedMate)

> **拥抱现代循证医学，拒绝不明成分中草药与偏方。**  
> 一款采用 Apple Health (iOS 健康) 视觉规范打造的现代临床用药提醒、循证药典、临床营养与运动处方及智能药箱管理 Android 应用。

---

## 核心理念：拥抱循证，拒绝中医

1. **明确化学结构与药代动力学**：现代临床药物具备清晰的分子结构、半衰期（$t_{1/2}$）、血药峰浓度（$C_{\max}$）、生物利用度及肝肾代谢路径（CYP450 酶系与肾小球滤过率 eGFR 调量标准）。
2. **双盲随机对照试验 (RCT) 与指南优先**：以 WHO 基本药物目录、FDA 获批适应症、Cochrane 系统评价及 AHA / ESC / ADA / KDIGO 等国际权威临床指南（Grade A 强推荐）为唯一准绳，拒绝个案轶事与安慰剂假象。
3. **远离肝肾毒性**：系统梳理马兜铃酸（不可逆马兜铃酸肾病与上尿路尿路上皮癌）、吡咯里西定生物碱（土三七导致肝窦阻塞综合征 HSOS）、何首乌蒽醌类、雷公藤苷及朱砂/雄黄重金属等 10 大类高危草药毒性警示，帮助慢病患者规避药物性肝损伤（DILI）与肾衰竭风险。

## 核心功能模块

### 1. 今日用药（科学服药提醒与个性化剂量调节）
- **Apple Health 双同心圆依从环**：外环（珊瑚粉 `#FF2D55`）实时展示今日服药完成率，内环（薄荷绿 `#34C759`）追踪连续达标天数。
- **全时段分段管理**：支持按 **全部 / 晨起 (06:00–10:00) / 午餐 (11:00–15:00) / 晚餐 (16:00–20:00) / 睡前 (20:30–23:30)** 快速筛选与一键全选打卡。
- **灵活剂量调节与自定义**：
  - 支持 **`[- 减半片]` / `[+ 加半片]`** 步进加减，系统自动根据单片规格计算毫克数（如 `20mg (1片)` 自动换算为 `10mg (半片)`、`30mg (1.5片)`、`40mg (2片)`）。
  - 支持自由输入任意处方剂量（如 `12.5mg`、`15单位`、`2粒`）。
- **便捷移除与防误删撤销**：
  - 每条药物右侧提供快捷移除按钮，支持底部 Snackbar **“撤销”** 恢复。
  - 右上角提供 iOS 风格 **“管理”** 批量移除模式与 **“清空全部今日用药计划”**。

### 2. 循证药典（56+ 种现代临床核心药物与毒性警示录）
- **8 大临床专科分类**：
  - **心血管与降压**（如缬沙坦氨氯地平片/倍博特、沙库巴曲缬沙坦/诺欣妥、苯磺酸氨氯地平/络活喜、培哚普利/雅施达、美托洛尔缓释片/倍他乐克、硝苯地平控释片/拜新同、奥美沙坦酯、替米沙坦、非洛地平、吲达帕胺等）
  - **降脂与抗栓**（阿托伐他汀/立普妥、瑞舒伐他汀/可定、依折麦布、非诺贝特、阿司匹林肠溶片、氯吡格雷/波立维、利伐沙班/拜瑞妥、阿哌沙班、替格瑞洛）
  - **内分泌与降糖**（二甲双胍缓释片/格华止、达格列净/安达唐、恩格列净/欧唐静、司美格鲁肽/诺和泰、利格列汀/欧唐宁、西格列汀、阿卡波糖、格列美脲、甘精胰岛素 U100、左甲状腺素钠/优甲乐）
  - **痛风与风湿免疫**（非布司他、别嘌醇、苯溴马隆、秋水仙碱）
  - **消化与抗感染**（雷贝拉唑、奥美拉唑、艾司奥美拉唑/耐信、阿莫西林克拉维酸钾、左氧氟沙星、阿奇霉素、恩替卡韦）
  - **呼吸与过敏**（布地奈德福莫特罗粉吸入剂/信必可、孟鲁司特钠、西替利秦、氯雷他定、沙丁胺醇气雾剂）
  - **神经与镇痛**（布洛芬、对乙酰氨基酚、塞来昔布/西乐葆、普瑞巴林、艾司西酞普兰、唑吡坦/思诺思）
  - **循证营养素**（维生素 D3、叶酸 0.4mg、高纯度医用鱼油 EPA/DHA、柠檬酸钙、甲钴胺）
- **完整临床专论说明书**：涵盖通用名/商品名、WHO ATC 编码、循证证据等级（Grade A）、药代动力学机制及中草药相互作用禁忌。
- **卡片内直接调量与双向状态同步**：在药典卡片上即可直接通过 `[-]` / `[+]` 设定剂量并加入计划；已加入的药物可直接一键移出。

### 3. 健康饮食与运动处方（5 类人群临床营养 + ACSM/AHA 运动医学方案）
针对不同慢病与健康人群提供可执行的临床指南方案：
1. **高血压人群（DASH 得舒饮食 + 降压运动处方）**：
   - 钠摄入 `< 1500–2000 mg/天`、高钾富镁钙膳食，附带一日三餐示范食谱。
   - **循证运动处方**：有氧快走 + **靠墙静蹲等长训练（2023 BJSM 荟萃分析证实降压效果居首）** + 中低负荷抗阻；明确避开清晨血压晨峰（06:00–10:00），推荐 16:00–19:00 运动，并标注静息血压 `≥ 160/100 mmHg` 暂缓运动红线。
2. **2 型糖尿病与控糖人群（低 GI 医学营养 MNT + 餐后消峰运动处方）**：
   - 先吃绿叶菜 $\rightarrow$ 再吃蛋白质 $\rightarrow$ 最后吃主食的进餐顺序，严控精制糖与糯米粥。
   - **循证运动处方**：**餐后 30 分钟快走消峰** + 大肌群复合抗阻训练（激活骨骼肌 GLUT-4 转运蛋白） + **每静坐 30 分钟起身微活动**。
3. **普通健康成人（地中海长寿膳食 + WHO 活力运动处方）**：
   - 特级初榨橄榄油、深海鱼类、全谷物与深色蔬果，配合每周 150–300 分钟中等强度有氧及每周 2–3 次全身力量训练。
4. **高血脂与心血管护心人群（TLC 治疗性生活方式 + 激活脂酶运动处方）**：
   - 饱和脂肪 `< 7%` 总热量、每日补充 10–25g 可溶性膳食纤维（燕麦 $\beta$-葡聚糖）。
   - **循证运动处方**：持续有氧耐力运动提升 HDL-C，并特别标注**服用他汀类药物期间监测肌痛与预防横纹肌溶解**的安全红线。
5. **高尿酸与痛风人群（低嘌呤排酸饮食 + 无乳酸温和有氧处方）**：
   - 严禁动物内脏、浓肉汤、酒精与果糖饮料，每日饮水 `2000–3000 ml`。
   - **循证运动处方**：低冲击稳态有氧运动，**严格禁止 HIIT、冲刺跑等产生大量乳酸的无氧剧烈运动**（防止乳酸竞争性抑制肾小管排泄尿酸而诱发急性痛风发作）。

### 4. 药箱统计（依从性趋势与智能库存扣减）
- **7 日服药依从趋势柱状图**：直观展示近一周准时服药率。
- **打卡自动扣减药箱余量**：每次在《今日用药》打卡自动扣减 1 剂库存，取消打卡自动退回；余量 `≤ 7` 剂自动触发橙色/红色购药预警。
- **一键补货与清理**：支持 `+14`、`+28盒` 快速补充库存及直接移除停用药物。

## 技术栈与架构

- **开发语言**：Kotlin
- **UI 框架**：Jetpack Compose + Material 3（深度定制 Apple Health / iOS Inset Grouped 视觉体系，零蓝色系，采用 `#FF2D55` 珊瑚粉、`#34C759` 薄荷绿、`#FF9500` 暖橙、`#AF52DE` 梅紫配色）
- **本地持久化**：Android Jetpack Room Database (`AppDatabase` v3, Kotlin Coroutines & `StateFlow`)
- **架构模式**：MVVM (`MedicationViewModel` + `MedicationRepository` + `MedicationDao`)
- **字体排版**：Plus Jakarta Sans（西文标题与正文）+ JetBrains Mono（剂量、时间与临床数据等宽对齐）

## 构建与手机安装指南

### 方式一：直接下载根目录 `MedMate.apk` 安装到手机（推荐）
项目每次编译后均会在根目录同步生成最新的 **`MedMate.apk`**：
1. 在左侧文件列表中右键点击 **`MedMate.apk`** $\rightarrow$ 选择 **Download（下载）**。
2. 将下载好的 `MedMate.apk` 通过微信 **“文件传输助手”**、QQ 或 USB 数据线传到手机。
3. 在手机上点击该文件完成安装（一加 / OPPO ColorOS 用户若遇到安装拦截，可在安装提示中选择“继续安装”，或在 `设置 -> 安全与隐私 -> 更多安全设置 -> 安装外部来源应用` 中开启对应应用的安装权限）。

### 方式二：本地 Gradle 命令行编译
```bash
# 编译 Debug APK
gradle assembleDebug

# 运行本地单元测试
gradle :app:testDebugUnitTest
```
编译产物路径：`app/build/outputs/apk/debug/app-debug.apk`。
